الثانوية العامة — Bot policy pages

1. Review privacy.html: confirm exactly what BotGhost logs, where logs are stored, how long they remain, and who can see them. Replace bracketed notes and add a reliable contact method.
2. Review terms.html and replace bracketed notes.
3. Create a GitHub repository under your own account (for example althanawiya-policies), and upload terms.html and privacy.html.
4. In Settings > Pages, choose Deploy from a branch, main, /(root). Wait for the Pages URL.
5. Use https://YOUR-USERNAME.github.io/althanawiya-policies/terms.html and https://YOUR-USERNAME.github.io/althanawiya-policies/privacy.html in Discord Developer Portal.
6. Public viewing of these pages is required; only repository collaborators can edit them. Protect GitHub with 2FA.
7. Restrict bot installation in Discord Developer Portal; separately restrict commands and server IDs in BotGhost. Policy text alone cannot enforce exclusivity.
